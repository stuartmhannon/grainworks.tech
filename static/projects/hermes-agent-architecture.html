Hermes Agent — Architecture & Information Flow

Nous Research · v0.18.2 · 15,485 commits · 215k stars

Input Surfaces

  • • CLI/TUI (prompt_toolkit REPL)
  • • Desktop App (Electron + React)
  • • Web UI (Vite + React + TypeScript)
  • • OpenAI-compatible API Server
  • • Platform channels (Telegram, Discord, Slack, Signal…)
  • • Computer Use (cua-driver desktop automation)

Core Agent Cycle (per turn)

  • • Build turn context (messages + tools + memory)
  • • Call LLM provider (with retries + fallbacks)
  • • Execute tool calls (sequential or concurrent, up to 8 workers)
  • • Apply tool guardrails (security, budget, idempotency)
  • • Compress context if needed
  • • Post-turn hooks (trajectory, verification, memory)

Key Architecture Decisions

  • • Exact-pinned dependencies (defense against supply chain attacks)
  • • Skills are procedural memory — self-improving on use
  • • Tool use enforcement: auto|must|none
  • • Profile system for multi-environment switching
  • • Cron scheduler runs 15,000+ concurrent job types
  • • Kanban for multi-profile worker dispatch
